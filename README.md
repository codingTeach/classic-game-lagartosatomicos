# Classic Game Lagartos Atómicos

**GALAGA** es un juego clásico de estilo arcade inspirado en los shooters espaciales tradicionales.  
El jugador controla una nave espacial cuyo objetivo es sobrevivir y eliminar oleadas de enemigos que aparecen en pantalla, evitando colisiones y ataques enemigos mientras aumenta su puntaje.

Este proyecto será desarrollado utilizando **A-Frame**, junto con **HTML, CSS y JavaScript**, permitiendo una experiencia interactiva en un entorno 3D accesible desde el navegador web. A-Frame facilita la creación de escenas y elementos tridimensionales, mientras que JavaScript se encarga de la lógica del juego, como el movimiento, las colisiones y el sistema de puntuación.

El juego busca recrear la esencia del GALAGA clásico, incorporando mecánicas sencillas, controles intuitivos y un diseño visual atractivo, aplicando conocimientos de desarrollo web, programación y gráficos interactivos.
